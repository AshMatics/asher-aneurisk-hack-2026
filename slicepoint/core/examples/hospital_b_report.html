Methods and limits

Methods

  1. The reference standard is your hospital's own labels and measurements, not an independent read.
  2. Primary sensitivity and specificity count a missing AI answer as wrong; the secondary “when answered” pair leaves those scans out.
  3. All ranges for proportions are 95% Wilson score intervals.
  4. Agreement uses AI minus label; the standard deviation divides by n (population SD).
  5. Groups with fewer than 15 scans are shown as “Too few”; sensitivity needs at least 3 aneurysms. These rules count scans, not people.
  6. Effective n is Kish's design-effect sample size over real people (ICC 1): repeat scans of one person carry less information than scans of different people.

Limits

  • The reference is “ref-hospital_a”, built from site “hospital_a” (100 cases). A fit check is only as good as its reference; ask the vendor for the model's own training or validation distribution.
  • The verdict rule is status-based: any Problem gives NO-GO, any Watch or check not run gives BORDERLINE, otherwise GO. It was inferred from the proof-of-concept and is pending ratification.
  • The label rule (30 mm) is specific to abdominal aortic aneurysm; the other checks apply to imaging AI generally.
  • Input today is a curated set of four parquet files. Readers for raw DICOM or PACS exports are not built yet.
  • This is a sample, not a trial: wide intervals mean the data cannot settle the question either way.
  • 0 to 100 check scores exist only as an unvalidated draft and are not shown in this report.
